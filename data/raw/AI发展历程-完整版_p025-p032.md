# 2020: GPT-3震撼发布

# 规模就是力量 (Scaling Laws)

2020年6月，OpenAI发布GPT-3（Generative Pre-trained Transformer 3），拥有1750亿参数，是GPT-2（15亿）的100倍以上。

![](images/e900cd44fd078637fd9696ccd6fb2ce5c51e45013d5b4ae3a0f7d60e7a0b2123.jpg)

# Few-shot Learning

无需微调，仅通过少量示例即可适应新任务  
展示了"涌现能力" (Emergent Abilities)   
一个模型可以完成翻译、写作、编程等多种任务

![](images/296fee32ed88ae9185aa576afe176ecaf67b890b8da3e5103e4be964577597a0.jpg)

# 训练规模

训练数据：45TB文本，过滤后约5000亿词  
训练算力：约314 GB的GPU内存，训练耗时数周   
训练成本：估计约460万美元（仅计算资源）

GPT-3让人们意识到：大模型的能力可以通过规模实现质变。

# 2022: ChatGPT引爆全球

# 史上增长最快的消费级应用

2022年11月30日，OpenAI发布ChatGPT（基于GPT-3.5），一个对话式AI助手。它2个月内用户破亿，刷新了消费级应用的增长记录。

# 为什么ChatGPT如此火爆？

极低的门槛：任何人都可以用自然语言交互  
强大的能力：写作、编程、翻译、分析...  
免费使用（初期）：降低了体验门槛  
社交媒体的病毒式传播

# 技术关键：RLHF

RLHF (Reinforcement Learning from Human Feedback)   
人类反馈强化学习：让AI输出更符合人类偏好  
使GPT-3.5从"能说"变成"会说人话"

ChatGPT的发布被认为是"AI的iPhone时刻"，开启了生成式AI的新纪元。

# 2023: GPT-4与多模态AI

# 多模态：从文本到全感官

2023年3月，OpenAI发布GPT-4，支持图像输入（多模态），并在各项考试中取得接近人类顶尖水平的成绩。

![](images/2c691e7807ea6ddd03d493b076289810793e0d70ae0fbcd3189c2813fe917965.jpg)

# GPT-4的能力展示

美国律师资格考试：模拟考试排名前10%  
生物学奥赛：前1%  
SAT阅读与写作：700分（满分800）  
能看懂图片并回答相关问题

![](images/f5ca539bb5471fe77956cb8093f45a53ef83f4ab072712f30f12fe27d3c071fb.jpg)

# 多模态AI浪潮

Google Gemini (2023.12)：原生多模态设计  
Claude 3 (Anthropic, 2024)：长文本理解（200K tokens）  
文生图：DALL-E 3、Midjourney V6、Stable Diffusion XL  
文生视频：Sora（OpenAI）、Runway Gen-2

# 开源大模型运动

# 开源 vs 闭源：AI的开放之争

ChatGPT发布后，开源社区迅速响应，推出了多个高性能开源大模型，降低了AI技术的使用门槛。

![](images/d27cf910191c5bac115202852a22ee06a871d976030578b58f0e5022f2d18ebd.jpg)

# 主要开源模型

LLaMA系列（Meta）：LLaMA 2、LLaMA 3  
Mistral 7B / Mixtral 8x7B: 小而精的代表  
Qwen（阿里通义千问）：中文能力出色  
ChatGLM（清华）：国产开源代表

![](images/60ae76be71b90dacff00bc3b978e784795542913cc94a9e7257d6ed273b24e04.jpg)

# 开源的意义

降低使用成本：无需依赖OpenAI API  
数据隐私：可在本地部署，数据不出域  
定制化：可以根据特定需求微调  
避免技术垄断，促进创新
