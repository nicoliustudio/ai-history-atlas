# 什么是人工智能？

# 学术定义

人工智能（Artificial Intelligence, AI）是计算机科学的一个分支，致力于创建能够模拟、延伸和扩展人类智能的理论、方法、技术及应用系统。

# 核心能力

感知（视觉、听觉、触觉）  
学习（从数据中获取知识）  
推理（逻辑推理、因果判断）  
决策（在不确定环境中选择）  
创造（生成新内容、新方案）

# 主要分支

机器学习（ML）  
深度学习 (DL)  
自然语言处理（NLP）  
计算机视觉（CV）  
机器人学（Robotics）

# AI的分类体系

# 按能力分类

弱人工智能

强人工智能

超人工智能

弱AI（ANI）：专用AI，擅长单一任务（如语音助手、图像识别）  
强AI（AGI）：通用AI，具备人类级别的综合智能  
▶ 超AI（ASI）：超越人类的超级智能

# 按功能分类

反应型

有限记忆

心智理论

自我意识

反应型AI：无记忆，纯反应（深蓝）  
有限记忆：利用历史数据（现代AI）  
心智理论：理解他人意图（未来）  
自我意识：真正自主意识（未来）

当前所有商用AI均为弱人工智能（ANI），AGI尚未实现，是当前研究的最前沿目标。

# AI发展三大浪潮

1950–1970

第一次浪潮：符号主义

核心思想：智能可以通过符号操作和逻辑推理实现

代表成果：逻辑理论家、通用问题求解器、ELIZA

结局：第一次AI寒冬（计算能力限制 + 预期过高）

1980-2000

第二次浪潮：连接主义萌芽

核心思想：智能源于大脑神经网络的结构

代表成果：反向传播算法、早期神经网络

结局：第二次AI寒冬（专家系统瓶颈 + 统计学习崛起）

2006-至今

第三次浪潮：深度学习 + 大模型

核心思想：深层神经网络 + 大规模数据 + 强大算力

代表成果：AlexNet、AlphaGo、GPT系列、多模态AI

现状：产业化加速，正在深刻改变社会

# 1950: 图灵测试与AI的哲学奠基

# Alan Turing的划时代论文

1950年，英国数学家 Alan Turing在《Mind》杂志发表《Computing Machinery and Intelligence》，提出：

"Can machines think?" (机器能思考吗？)

# 图灵测试（Turing Test）

测试者通过文字对话区分机器和人类  
如果机器能骗过测试者 → 认为其具有智能  
这一标准影响了AI研究数十年

# 历史意义

首次给出"机器智能"的可操作定义  
将哲学问题转化为工程问题  
为AI作为独立学科奠定基础

# 1956: 达特茅斯会议——AI正式诞生

# 历史上的这个夏天

1956年夏季，在美国新罕布什尔州的达特茅斯学院，John McCarthy、Marvin Minsky、Claude Shannon、Nathaniel Rochester等学者聚集，提出"人工智能"这一术语。

# 关键人物

John McCarthy (LISP语言发明者)   
Marvin Minsky（神经网络早期研究者）  
Claude Shannon（信息论之父）  
Herbert Simon（诺贝尔经济学奖得主）

# 会议目标

研究"让机器使用语言、形成抽象概念"  
预言"在不到一个世代的时间内，AI将取得重大进展"  
正式确立AI为独立研究方向

# 1950s- 1960s: 早期乐观主义与重要成果

1956

# 逻辑理论家 (Logic Theorist)

Allen Newell和Herbert Simon开发，能证明数学定理

被认为是第一个AI程序

1958

# LISP语言诞生

John McCarthy发明LISP，成为AI研究的主导语言

引入了递归、垃圾回收等革命性概念

1966

# ELIZA：第一个聊天机器人

Joseph Weizenbaum开发，模拟心理治疗师

展示了"人机对话"的可能性，但也暴露了符号AI的局限

# 1970s: 第一次AI寒冬

# 期望过高，现实骨感

1960年代的过度乐观导致了1970年代的失望和资金撤回，AI进入第一个"寒冬"。

# 寒冬原因

计算能力严重不足（当时计算机内存仅几KB）  
组合爆炸问题：符号推理在复杂问题中不可扩展  
常识推理难题：机器缺乏世界知识   
资金大幅缩减（DARPA等机构削减AI预算）

# 7 标志性事件

1973年：英国政府发布"Lighthill报告"，批评AI进展甚微  
1970s中期：美国国防部大幅削减AI研究经费  
神经网络研究陷入低潮（被符号AI边缘化）

教训：AI研究需要谦逊和长期主义，过度炒作必然导致反弹。

# 专家系统时代

1980年代 - 1990年代：商业化尝试与第二次浪潮

从专家系统的兴起到第二次AI寒冬·日本第五代计算机计划的启示

# 1980s: 专家系统的兴起与商业化

# 什么是专家系统？

专家系统（Expert System）是一种基于知识库和推理引擎的AI程序，通过模拟人类专家的决策过程来解决特定领域的问题。

![](images/4099088ca14b09223cb4cfcefcc9d27626f7cb8bfbf95e69c4cdaad68e7f7e75.jpg)

# 代表性专家系统

MYCIN (1976)：医疗诊断，识别细菌感染  
DENDRAL（1965）：化学分析，推断分子结构  
XCON（1980）：计算机配置，为DEC公司节省数千万美元

![](images/ef8caac615baca4d07170de5aca1a3c3e5e9274ab0cfaa3a9cb23c59d2c69448.jpg)

# 商业化成功

专家系统公司如雨后春笋般涌现  
1980s中期：AI产业规模达数十亿美元  
日本"第五代计算机"计划投入10亿美元  
各国政府纷纷启动国家级AI计划

# 1987-1993: 第二次AI寒冬

# 专家系统的瓶颈

尽管专家系统在限定领域取得了成功，但它们面临着难以克服的根本性缺陷。

# 专家系统的局限

知识获取瓶颈：专家知识难以形式化  
维护成本高：规则库难以扩展和更新  
脆弱性：超出设计范围则表现糟糕  
无法学习：依赖人工编码，不能自主改进

# 寒冬来临

1987年：桌面计算机性能提升，削弱专用AI硬件需求  
1990s初：专家系统市场崩溃  
统计学习方法崛起（SVM、决策树）  
神经网络研究在低谷中悄然积累

# 1997: IBM深蓝击败国际象棋冠军

# 历史性对决

1997年5月，IBM的超级计算机"深蓝"（Deep Blue）以3.5:2.5的总比分击败了国际象棋世界冠军加里·卡斯帕罗夫（Garry Kasparov）。

![](images/d84b128363a8c98d48630d8e24ab6db252560615f5f42c20e810d112e8acc723.jpg)

# 技术成就

深蓝每秒可评估2亿个棋局  
使用专门的硬件加速器  
结合了暴力搜索和启发式评估   
标志着AI在特定领域超越人类

![](images/4596a17e7c90abdd1ca1e7e3f3a5c57ab2f73a830520bb8c6a0b1d816f474e02.jpg)

# 社会影响

公众对AI的关注度大幅提升  
引发关于"机器是否会取代人类"的讨论  
但国际象棋被认为是"有限状态游戏"，与通用智能仍有差距

深蓝的成功证明了：在规则明确、状态空间可控的领域，AI可以超越人类。

# 2000s: 机器学习的崛起

# 从规则驱动到数据驱动

1990s-2000s，AI研究的重心逐渐从"手工编码知识"转向"从数据中自动学习”，机器学习成为主流范式。

![](images/129171dbdbc2d3865770682d8ac9bc1cf87335c4f81c835bb9d659e99004d0a2.jpg)

# 关键算法

支持向量机（SVM）：Vapnik等，1990s  
随机森林（Random Forest）：Breiman, 2001  
AdaBoost: Freund & Schapire, 1997   
贝叶斯网络、隐马尔可夫模型

![](images/738ab927d79b245177f2608783ea59a28a63343662d759a07b8305a0e8490027.jpg)

# 理论进展

统计学习理论（Statistical Learning Theory）  
VC维 (Vapnik-Chervonenkis Dimension)   
贝叶斯推理与图模型  
为深度学习的爆发奠定了理论基础

# 深度学习革命

2010年代：神经网络的重生与AI的爆发

从Hinton的突破性论文到AlphaGo的横空出世·深度学习改变世界

# 2006: 深度学习的重生

# Geoffrey Hinton的突破性论文

2006年，Geoffrey Hinton等人在《Science》发表《A Fast Learning Algorithm for Deep Belief Nets》，提出了深度信念网络（DBN）和逐层预训练方法，解决了深层神经网络训练困难的问题。

![](images/f6242e512f1eaade1bbbabd4ec41ada099d0030c03ea6e11a162e314f38cd79a.jpg)

# 关键技术突破

逐层预训练（Layer-wise Pre-training）  
受限玻尔兹曼机（RBM）  
解决了"梯度消失"问题  
使得训练10层以上网络成为可能

![](images/f6c960ceb3fd29c3334f0c213ca85a8fec3affb4aebece3402bebb22d109a755.jpg)

# 深度学习三巨头

Geoffrey Hinton: 多伦多大学，深度学习奠基人  
Yann LeCun：纽约大学，卷积神经网络先驱  
Yoshua Bengio：蒙特利尔大学，深度学习理论贡献  
三人共同获得2018年图灵奖

# 2012: AlexNet与ImageNet的突破

# ImageNet大规模视觉识别竞赛（ILSVRC）

2012年，Alex Krizhevsky、Ilya Sutskever和Geoffrey Hinton开发的AlexNet在ImageNet竞赛中，将图像识别错误率从 $26\%$ 降低到 $15.3\%$ ，引发了深度学习革命。

![](images/e781d2652c169cc3b39b4b9cad00b5c70c9fd87054dee3d83d87d33f5f13aaff.jpg)

# AlexNet的创新

使用GPU进行训练（NVIDIA GTX 580）  
ReLU激活函数（解决梯度消失）  
Dropout技术（防止过拟合）  
数据增强（Data Augmentation）

![](images/0cfb6ea5bbc6f00dff1daa252de65669f840b438ab5454665ecce3544b81ccc8.jpg)

# 深远影响

计算机视觉领域全面转向深度学习  
GPU成为AI训练的标配  
NVIDIA股价随之飙升，引领AI硬件市场   
开启了"深度学习每一年都在ImageNet上刷榜"的时代

# 卷积神经网络（CNN）的演进

# CNN架构的快速迭代（2012–2015）

AlexNet之后，CNN架构快速演进，图像识别精度逐年提升，最终超越人类水平。

2013

ZFNet

对AlexNet进行改进，进一步降低错误率

2014

VGGNet & GoogLeNet

VGGNet：更深的网络（16–19层）·GoogLeNet：Inception模块，参数更少

2015

ResNet (残差网络)

微软研究院，152层网络，错误率仅3.57%，超越人类（约5%）

ResNet的"跳跃连接"（Skip Connection）解决了深层网络训练难题，成为深度学习里程碑。

# 2016: AlphaGo击败李世石

# AI在"人类最后堡垒"的胜利

2016年3月，Google DeepMind开发的AlphaGo以4:1击败世界围棋冠军李世石。围棋曾被认为是AI无法攻克的"圣杯"，因为搜索空间（10^170）远超宇宙原子数。

![](images/b0755d2ad9f9fb312cb7fe5ad62096cad4555394b264a90ed5715f5acc0b85e1.jpg)

# AlphaGo的技术

深度卷积神经网络（策略网络 + 价值网络）  
蒙特卡洛树搜索（MCTS）  
强化学习（自我对弈，提升能力）  
训练耗时：约4-6周，使用50个GPU

![](images/055f6e26bc97da03681cb95bbf387ec8ef02124ab392cefa100dccf03006dfa5.jpg)

# 第二局"神之一手"

第37手：AlphaGo下出了人类棋手认为"不可能"的一手  
最终证明这一手是制胜关键  
展示了AI可以"创造"超越人类经验的策略

AlphaGo之后，AI又击败了围棋世界排名第一的柯洁（2017），并进化出完全自我学习的AlphaGo Zero和AlphaZero。

# 大模型时代

2020年代 – 至今：从专用AI到通用智能的跨越

Transformer架构引爆大模型革命·ChatGPT改变世界·多模态AI加速到来

# 2017: Transformer架构的诞生

# "Attention is All You Need"

2017年，Google团队（Ashish Vaswani等）发表论文《Attention is All You Need》，提出了Transformer架构，彻底改变了自然语言处理领域。

![](images/4d838fbaa81c662d866dd87f6815436962e6241ec2145658fff8b85f5f2f885d.jpg)

# 核心创新：自注意力机制

不再依赖RNN的序列处理，实现并行计算  
注意力机制：每个词可以"关注"句子中的所有其他词  
解决了RNN的长距离依赖问题  
多头注意力（Multi-Head Attention）：捕捉多种关系

![](images/d3634c3e95e310ea714a2b90a5680a193ae2d819c95c1e2f8639878c13bd7e0b.jpg)

# 深远影响

Transformer成为BERT、GPT等所有大模型的基础  
论文引用量超10万次（截至2024年）  
被认为是"21世纪最重要的计算机科学论文之一"

# BERT与GPT：预训练大模型的两大路线

# 2018- 2019: 预训练 + 微调范式确立

Transformer之后，NLP领域出现了两条主要技术路线：BERT（双向编码）和GPT（自回归生成）。

# BERT (Google, 2018)

Bidirectional Encoder Representations from Transformers   
双向编码器：同时考虑左右上下文  
擅长：文本理解、分类、问答  
预训练任务：Masked Language Modeling

# GPT (OpenAI, 2018-)

Generative Pre-trained Transformer   
自回归解码器：从左到右生成  
擅长：文本生成、对话、创作  
预训练任务：Next Token Prediction

最终，GPT路线因更强的生成能力和扩展潜力，成为大模型时代的主流选择。

# 2020: GPT-3震撼发布

# 规模就是力量 (Scaling Laws)

2020年6月，OpenAI发布GPT-3（Generative Pre-trained Transformer 3），拥有1750亿参数，是GPT-2（15亿）的100倍以上。

![](images/e900cd44fd078637fd9696ccd6fb2ce5c51e45013d5b4ae3a0f7d60e7a0b2123.jpg)

# Few-shot Learning

无需微调，仅通过少量示例即可适应新任务  
展示了"涌现能力" (Emergent Abilities)   
一个模型可以完成翻译、写作、编程等多种任务

![](images/296fee32ed88ae9185aa576afe176ecaf67b890b8da3e5103e4be964577597a0.jpg)

# 训练规模

训练数据：45TB文本，过滤后约5000亿词  
训练算力：约314 GB的GPU内存，训练耗时数周   
训练成本：估计约460万美元（仅计算资源）

GPT-3让人们意识到：大模型的能力可以通过规模实现质变。

# 2022: ChatGPT引爆全球

# 史上增长最快的消费级应用

2022年11月30日，OpenAI发布ChatGPT（基于GPT-3.5），一个对话式AI助手。它2个月内用户破亿，刷新了消费级应用的增长记录。

# 为什么ChatGPT如此火爆？

极低的门槛：任何人都可以用自然语言交互  
强大的能力：写作、编程、翻译、分析...  
免费使用（初期）：降低了体验门槛  
社交媒体的病毒式传播

# 技术关键：RLHF

RLHF (Reinforcement Learning from Human Feedback)   
人类反馈强化学习：让AI输出更符合人类偏好  
使GPT-3.5从"能说"变成"会说人话"

ChatGPT的发布被认为是"AI的iPhone时刻"，开启了生成式AI的新纪元。

# 2023: GPT-4与多模态AI

# 多模态：从文本到全感官

2023年3月，OpenAI发布GPT-4，支持图像输入（多模态），并在各项考试中取得接近人类顶尖水平的成绩。

![](images/2c691e7807ea6ddd03d493b076289810793e0d70ae0fbcd3189c2813fe917965.jpg)

# AI发展面临的挑战

# ! 技术挑战

AI对齐问题（Alignment Problem）：确保AI目标与人类价值一致  
可解释性：深度学习是"黑盒"，难以解释决策过程  
幻觉问题（Hallucination）：大语言模型会"编造"不存在的事实  
算力瓶颈：大模型训练需要巨大算力，成本高昂

# 社会挑战

就业替代：全球约3亿全职岗位可能被AI影响  
隐私安全：AI需要大量数据，引发隐私担忧  
深度伪造（Deepfake）：虚假信息、诈骗、政治操纵  
算法偏见：训练数据偏见导致AI决策歧视性

# 伦理与治理

AI安全研究：防止超级智能失控
