# 自我博弈强化学习

AlphaGo Zero完全无需人类棋谱，仅凭围棋规则从零开始，通过数百万局自我对弈不断迭代策略。强化学习以胜率为奖励信号驱动网络进化，仅72小时即超越所有人类与前代版本。

# QKV计算流程

输入向量分别乘以权重矩阵，生成Query、Key、Value三个向量，通过缩放点积计算注意力权重并加权求和

Attention(Q,K,V) = softmax(QKᵀ/√d)V

![](images/c7f5098d1126f1bf41ac127853c32c5684892309a299ca4ce5927b582b19cede.jpg)

# 多头注意力

将注意力机制并行执行多次，每个头使用不同投影矩阵，捕获语法、语义等多层面关系，最终拼接融合

MultiHead = Concat(head₁...
    headₕ)W°

![](images/f9511961e23385a1cf9bf3bff49f8bd08899473658cbddde0eb0a61f029985b4.jpg)

# 位置编码

自注意力本身不含序列位置信息，通过正弦与余弦函数生成位置编码向量，为模型注入顺序感知能力

PE(pos,2i) =
sin(pos/10000^(2i/d))

# GPT vs BERT: 两大预训练范式

# GPT

Generative Pre-trained Transformer

→ 自回归语言模型  
逐token预测下一个词的概率分布  
→ 从左到右单向生成  
仅利用前文上下文，因果注意力掩码  
→ 擅长文本生成任务  
对话、写作、代码生成、创意内容  
→ Decoder-only架构  
参数规模可扩展性强，适合大规模训练

GPT-4

# BERT

Bidirectional Encoder Representations

→ 双向编码语言模型  
同时利用左右上下文信息进行编码  
→ 掩码语言建模（MLM）  
随机遮盖15%的token并预测被遮盖词   
→ 擅长文本理解任务  
文本分类、信息检索、问答、命名实体识别  
→ Encoder-only架构  
全局双向自注意力，深度语义表征能力强
